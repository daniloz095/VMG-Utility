# Получение oap-sdk с головной части (опционально, только для разработки)

BMW SDK (`oap-sdk`) — это код BMW, защищённый авторским правом, поэтому его нет
ни в одном репозитории. Он лежит внутри «официальных» онлайн-приложений на самой
головной части.

> **Важно:** для сборки релизного `.mgu` и для установки приложения `oap-sdk`
> **не нужен**. `build.py` собирает пакет без SDK — модули HU (`os`, `signals`,
> `diagnostic`, …) подхватываются на машине во время выполнения через шимы.
> `oap-sdk` может понадобиться только если вы хотите локально инспектировать
> реальный код BMW или поднять эмулятор на настоящем SDK (сейчас эмулятор
> `emu.js` работает на мок-ответах и SDK не использует).

## Шаг 1. Скопировать приложение-донор с HU

На машине: зажигание включено, автомобиль припаркован. С вашего ПК:

```sh
# Linux / macOS / WSL
scp root@<IP-головки>:'/usr/lib/oap-mainapp/preinstalled_apps/x_call@*.tgz' .
mkdir x_call && tar xzf x_call@*.tgz -C x_call
```

Windows (PowerShell — `scp` и `tar` встроены):

```powershell
scp "root@<IP>:/usr/lib/oap-mainapp/preinstalled_apps/x_call@*.tgz" .
mkdir x_call
tar -xzf (Get-ChildItem x_call@*.tgz).Name -C x_call
```

Если по этому пути нет `x_call` (прошивка может отличаться), посмотрите, что есть:

```sh
ssh root@<IP> 'ls /usr/lib/oap-mainapp/preinstalled_apps/'
```

Вариант посвежее — приложение, которое машина скачала сама; его SDK новее (27.x):

```sh
scp root@<IP>:/var/opt/public/oap/oap_12204/source/javascript/app.js ./app.js
```

Прошивочный `x_call` несёт SDK 24.10.x с полным публичным API — предпочтительный донор.

## Шаг 2. Извлечь SDK

```sh
node kit/tools/extract_sdk.js x_call/javascript/app.js     # пишет ./oap-sdk/
```

Результат:

| Путь | Что это |
|---|---|
| `oap-sdk/sdk/<module>.js` | каждый найденный модуль SDK отдельным файлом (обёртка-фабрика `module.exports = function(module, exports, require){…}`) |
| `oap-sdk/index.json` | манифест: источник, дата генерации, список модулей |

Инструмент парсит карту модулей бандла (`webpack`/`___OAP_MODULE_*___`) и вырезает
исходники сбалансированными скобками. Если донор был с урезанным SDK, часть модулей
может не найтись — `index.json` покажет, какие извлеклись.

## Шаг 3. Никогда не коммитить SDK

Папка `oap-sdk/` должна быть в `.gitignore` (в этом репозитории — есть). Это код
BMW: храните только для своей машины, нигде не публикуйте.

> Сам собранный `.mgu` код BMW **не содержит** (внутри — только приложение и шимы),
> поэтому его можно публиковать в GitHub Releases.
